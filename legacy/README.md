# Legacy: grid autobattler

This folder holds the previous version of Lee: a grid-based autobattler with
Lees, drafting, merging, a Spire-style map, a shop, and the Lee creator tool.

It is **not** part of the current build or npm install. It is kept for
reference only (the crew/Lee data may be useful once crew return in the
ranged-combat game). To run it, `cd legacy && npm install && npm run dev:game`.
