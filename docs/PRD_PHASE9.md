# Lee — Phase 9: Bosses (to plan)

> **Status:** Not planned yet. This is a placeholder holding what's decided so far and what to work out. Write the full PRD once Phases 7 ([`PRD_PHASE7.md`](PRD_PHASE7.md)) and 8 ([`PRD_PHASE8.md`](PRD_PHASE8.md)) are built and playtested.

## Decided so far

- **Bosses can be Nesses, ships, or a mix** (a flagship with an escort, a Ness with a pirate crew that keeps it...).
- **Most bosses are just really tough enemies**, built from the same content as everything else.
- **Final bosses have phases.**
- Bosses use the attack and danger-zone system from Phase 8 and the connections from Phase 7.
